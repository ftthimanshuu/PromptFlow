Problem Context

The Automation Gap

Why Traditional Web Scraping & RPA Tools Fail in Modern Workflows
  • High Technical Barrier: Traditional automation requires mastering Python/Node.js, headless browsers (Selenium, Playwright), and regex.
  • DOM Fragility: Minor frontend redesigns or A/B testing variants break static CSS and XPath selectors silently, causing lost alerts.
  • Critical Security Hazards (SSRF): Naive user-defined scraping engines expose servers to Server-Side Request Forgery against cloud metadata.
  • Inflexibility with Ambiguity: Conventional scripts crash on incomplete inputs rather than engaging in conversational clarification dialogues.
  • High Maintenance Overhead: Developers spend more time fixing broken selectors than using the actual data.

Core Solution

The PromptFlow Paradigm

Conversational Compilation to a Deterministic 4-Step Pipeline
  • Conversational AI Compiler: Synthesizes natural language into an immutable, schema-validated 4-step DSL: Scrape → AI Filter → Condition → Notify.
  • Multi-Turn Slot-Filling: Automatically detects missing parameters (URLs, thresholds) and asks conversational clarification questions.
  • Zero-Selector Semantic Extraction: Extracts targeted entities (price, title) using schema-constrained LLMs without brittle CSS paths.
  • Deterministic Rule Engine: Evaluates dynamic conditions (<, >, ==, contains) with automatic currency sanitization.
  • Short-Circuit Execution: Gracefully halts in a SKIPPED state if conditions evaluate to false, eliminating notification spam.

System Architecture

Full-Stack Architecture & Engineering Stack

Engineered for Low Latency, Memory Safety, and Enterprise Security
  • Frontend Client: React 18, TypeScript, Tailwind CSS, custom Apple Glassmorphism tokens with spring physics.
  • Backend Engine: Node.js, Express, TypeScript, Cheerio scraping sandbox with automated browser user-agent rotation.
  • Machine Intelligence: Groq LPU (Llama-3.3 70B) for sub-second compilation + Google Gemini Flash automatic fallback.
  • Pre-Socket SSRF Firewall: DNS inspection actively blocking loopbacks, private CIDRs (10.0.0.0/8), and AWS metadata (169.254.169.254).
  • Cloud Persistence & Quota: Supabase PostgreSQL with Row-Level Security (RLS) and a strict 5-active automation quota trigger.

Roadmap & Conclusion

Future Roadmap & Conclusion

Expanding Micro-Automations to Enterprise Ecosystems
  • Complex Logical DAGs: Transitioning from linear 4-step pipelines to branching Directed Acyclic Graphs (IF / ELSE).
  • Event-Driven Webhook Triggers: Adding incoming webhooks (GitHub, Stripe, Shopify) alongside cron scheduling.
  • Distributed Scaling: Decoupling workers via Redis & BullMQ job queues for horizontal worker cluster execution.
  • Enterprise Channels: Native connector plugins for Slack Enterprise, Microsoft Teams, and WhatsApp Business API.
  • Summary: PromptFlow proves modern AI can eliminate technical friction while preserving strict engineering rigor.
