Channel Setup Guide

Connect where PromptFlow should deliver your alerts.

Discord

  1. Create a Discord Server (or pick yours).
  2. Open Channel Settings.
  3. Go to Integrations.
  4. Choose New Webhook.
  5. Copy Webhook URL and paste it into PromptFlow.

Telegram

  1. Search @BotFather in Telegram.
  2. Send /newbot and follow the prompts.
  3. Copy the bot token it gives you.
  4. Message @userinfobot to get your Chat ID.
  5. Paste the token and Chat ID into PromptFlow.

Gmail / Email

  1. Open Manage your Google Account.
  2. Go to Security.
  3. Turn on 2-Step Verification.
  4. Open App Passwords.
  5. Copy the 16-character key into PromptFlow.
